# CRE Morning Brief

A tiny, installable, offline-capable reader for free Chicago commercial real estate news.

- `news.json` — the day's articles (updated each weekday morning by a scheduled task)
- `index.html` — the app (text only, ~8 KB)
- `sw.js` — caches the app and the latest brief so it opens offline
- `manifest.json` + `icons/` — lets it install to your home screen

Hosted on GitHub Pages. To install: open the site on your phone → Share → Add to Home Screen (iPhone) or ⋮ → Install app (Android).
